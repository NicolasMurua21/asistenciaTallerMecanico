# asistenciaTallerMecanico
Trabajo para la materia practica profesionalizante 1.

Sistema web local para la digitalización del control de asistencia, gestión de turnos y generación de reportes horarios para el personal de taller.

## 🚀 Características Principales

* **Fichado Rápido:** Registro de ingreso, egreso y salidas intermedias mediante DNI.
* **Operación Offline:** Funcionamiento local continuo sin dependencia de conexión a internet.
* **Procesamiento de Datos:** Cálculo automático de horas trabajadas y gestión de turnos rotativos.
* **Generación de Reportes:** Exportación de asistencias consolidada en formato Excel (`.xlsx`).
* **Interfaz Adaptada:** Diseño pensado para entornos de taller (PC de escritorio y botones de fácil interacción).

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript Vanilla.
* **Backend:** Python (Flask).
* **Base de Datos:** SQLite.
